## 📝 Descrição do Projeto
O **Solidariedade Já** é uma aplicação desenvolvida com o objetivo de conectar empresas que desejam realizar doações a instituições e projetos sociais. A plataforma visa simplificar o processo de solidariedade, servindo como uma ponte eficiente e intuitiva para quem precisa de ajuda e quem tem algo a oferecer (como alimentos, agasalhos e produtos de higiene). Além de dar visibilidade para essas instituições.

Pode aceder à aplicação em tempo real através do link: [Solidariedade Já - Live](https://nanatutida.github.io/SolidariedadeJa/)

---

## ✨ Funcionalidades
* `Visualização de Campanhas:` Listagem de ações solidárias ativas que necessitam de apoio.
* `Itens Necessários:` Separação do tipo de doação que os Projetos Sociais necessitam (ex: Alimentos, Roupas, Higiene).
* `Visibilidade para Doadores:` Listagem das Empresas doadoras e links para seus sites.
* `Interface Responsiva:` Design adaptável para proporcionar uma boa experiência tanto em computadores como em dispositivos móveis.
